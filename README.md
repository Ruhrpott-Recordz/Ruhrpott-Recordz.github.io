# Ruhrpott Recordz Website

- `index.html` – komplette responsive Website
- `assets/from-germany-to-the-bay.png` – Titelmotiv / kommendes Projekt
- `assets/monroe-promo.png` – Promo-Motiv

## Lokal ansehen
`index.html` im Browser öffnen.

## Auf GitHub Pages veröffentlichen
1. Erstelle ein GitHub-Repository.
2. Lade `index.html` und den gesamten Ordner `assets/` hoch.
3. Öffne **Settings → Pages**.
4. Wähle **Deploy from a branch**, Branch `main`, Ordner `/ (root)`, dann **Save**.

## Vor Veröffentlichung anpassen
- Ersetze die allgemeinen YouTube-, Instagram- und SoundCloud-Links in `index.html` durch deine echten Profil-URLs.
- Ergänze bestätigte Release-Links und Credits, sobald sie vorliegen.
- `From Germany to the Bay` ist aktuell als kommendes Projekt markiert; es gibt keinen erfundenen Veröffentlichungstermin oder Streaming-Link.
